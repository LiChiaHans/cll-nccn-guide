# CLL / SLL 慢性淋巴球性白血病 — NCCN v2.2027 臨床速查手冊

基於 **NCCN Clinical Practice Guidelines in Oncology: Chronic Lymphocytic Leukemia/Small Lymphocytic Lymphoma (Version 2.2027, September 28, 2026)** 整理之繁體中文臨床重點與快速查找網站。

## 功能特色
- **章節快速導覽與全文即時搜尋**：支援 `/` 快捷鍵、關鍵字高亮、藥物／基因／分期／副作用即時檢索。
- **v2.2027 & v1.2027 重大更新整理**：二線新增 **Venetoclax / Pirtobrutinib + Rituximab**（BRUIN CLL-322，cBTKi 後 Cat 1）、一線依 Fit/Frail 與 IGHV 狀態重組、一線特定情況新增 Pirtobrutinib、BTKi 惡化停藥爆發性反彈與偽轉化警語、CAR-T 早期轉介評估、Richter 轉化新增 Pirtobrutinib/Venetoclax + Obinutuzumab。
- **雙互動式臨床工具**：
  1. **Rai / Binet / CLL-IPI 綜合計算機**：即時計算 Rai 分期、Binet 分期與 CLL-IPI 總分及風險分層。
  2. **Venetoclax TLS 風險分層與處置速查**：依 CT 淋巴結大小、ALC 與 CrCl 即時提供水化、降尿酸與住院監測建議。
- **完整臨床速查表格**：CLL/SLL/MBL 診斷與 MCL 鑑別、iwCLL 治療適應症、FISH/TP53/IGHV/CK 預後與抗藥突變、一線與 R/R 治療序貫及關鍵試驗數據、MRD 導向治療、Richter 轉化、HBV/CMV/PJP 預防、BTKi 圍手術期停藥與副作用比較、疫苗接種。
- **回到首頁（血液科入口網）按鈕**與**深色／淺色模式切換**，支援桌面與行動裝置瀏覽。
